# Responsive Contact Form

Projeto desenvolvido com HTML e CSS que apresenta uma página de contato moderna e responsiva. O layout divide as informações de contato e o formulário de mensagens em duas seções organizadas para melhorar a experiência do usuário.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Font Awesome

## ✨ Funcionalidades

- Formulário de contato
- Campo para nome
- Campo para e-mail
- Campo para mensagem
- Informações de endereço
- Informações de telefone
- Informações de e-mail
- Layout responsivo
- Ícones personalizados

## 📂 Estrutura do Projeto

```bash
Responsive-Contact-Form/
```

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em qualquer navegador.
